# 🏠 AI Housing Agent for NOVA Students

This project is an AI-powered housing assistant built to help incoming students at NOVA SBE find ideal apartments based on rent, commute, bedrooms, and lifestyle preferences.

## Features
- Smart filtering (rent, commute, size, cluster)
- Lifestyle-based clustering (Student Friendly, Moderate Budget, etc.)
- Interactive map of listings
- Export results to CSV
- Web interface via Streamlit
